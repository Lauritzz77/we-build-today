# We Build Today

## Stack

- Astro 6 + Tailwind CSS v4 + TypeScript
- Deployed on Cloudflare
- Package manager: pnpm

## Commands

- `pnpm dev` — start dev server
- `pnpm build` — production build

## Tailwind v4

- Uses `@tailwindcss/vite`
- Config lives in `src/styles/global.css` via `@theme {}` blocks
- `tailwind-clamp` plugin for fluid responsive sizing
